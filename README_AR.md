# SCORM Course Editor — MVP

محرر محلي مبني خصيصًا لبنية المقرر الذي تم تحليله: `SCORM 1.2 + HTML/JavaScript/JSON`.

## ماذا يفعل الآن؟

- يفتح ملف ZIP يحتوي على:
  - حزمة SCORM مباشرة، أو
  - مجموعة من ملفات ZIP الداخلية، كل واحد منها وحدة SCORM.
- يكتشف `LO/json/course.json` تلقائيًا.
- يعرض الوحدات والشاشات في قائمة واضحة.
- يدعم تحرير:
  - عنوان الشاشة.
  - `screenText` في قوالب `video` و `sync` وغيرها عندما يكون الحقل موجودًا.
  - الأنشطة والاختبارات (`choice`, `multipleChoice`, `matching`, `sorting`).
  - نسبة النجاح في الاختبارات.
  - JSON الخام لأي قالب غير معروف.
  - بيانات الوحدة: اسم المقرر، عنوان الوحدة، ومرجع PDF.
- يكتشف الوسائط المرتبطة بالشاشة، ويتيح معاينتها واستبدالها.
- يحافظ على الملفات الأصلية الأخرى دون تغيير.
- إذا وجد نسخة ZIP من الوحدة ونسخة مفكوكة مكررة داخل الملف الخارجي، يحدّث النسختين عند التصدير.
- يفحص `imsmanifest.xml` وملفات الشاشات قبل التصدير.
- يصدر ملفًا جديدًا باسم `_edited.zip` ولا يكتب فوق الملف الأصلي.

## التشغيل

يتطلب Python 3.10 أو أحدث، ولا يحتاج إلى تثبيت مكتبات Python خارجية. ويستخدم أداة `zip` الموجودة افتراضيًا على macOS/Linux كمسار تسريع إن كانت متاحة، مع fallback داخل Python.

### Windows

```bat
python server.py
```

### macOS / Linux

```bash
python3 server.py
```

ثم افتح:

`http://127.0.0.1:8765`

## طريقة الاستخدام

1. اضغط **فتح مقرر**.
2. اختر ملف ZIP الأصلي.
3. اختر الوحدة ثم الشاشة.
4. عدّل النص أو الأسئلة أو الإجابات.
5. اضغط **حفظ الشاشة**.
6. استخدم **فحص المقرر**.
7. اضغط **Export SCORM**.

## حدود الـMVP الحالية

- المحرر يعرف نماذج الأسئلة الموجودة في المقرر التجريبي. أي بنية أخرى تبقى قابلة للتعديل من تبويب JSON.
- المعاينة ليست تشغيلًا كاملاً لمحرك SCORM؛ هي معاينة للمحتوى داخل المحرر.
- التصدير يعيد بناء ZIP باستخدام مكتبة Python القياسية؛ لذلك مع مقررات كبيرة جدًا قد يكون الإنتاج النهائي أسرع إذا أضفنا طبقة تحديث ZIP محسّنة.
- لا توجد إدارة مستخدمين أو قاعدة بيانات أو version history بعد؛ هذه مميزات مرحلة المنتج المؤسسي.

## الاتجاه المقترح للنسخة المؤسسية

- Batch Import للـ52 مقررًا.
- Course Library مع بحث وتصنيف.
- Versioning + مقارنة قبل/بعد + Rollback.
- Workflow للمراجع والموافقات.
- Rich Text Editor بدل تحرير HTML الخام.
- إدارة مركزية للصور والفيديو والصوت.
- فحص الروابط والوسائط المفقودة تلقائيًا.
- SCORM Preview حقيقي داخل Sandbox.
- Export لكل مقرر أو Bulk Export.
- Audit Log وصلاحيات Editor / Reviewer / Admin.

## تشغيل عبر الإنترنت (جديد)

راجع `README_ONLINE_AR.md`. بعد تثبيت `cloudflared` شغّل:

```bash
./run_public_mac_linux.sh
```

أو على Windows:

```text
run_public_windows.bat
```

سيتم إنشاء رابط HTTPS عام مؤقت مع Basic Authentication وكلمة مرور عشوائية لكل تشغيل. كما أصبحت عملية رفع المقرر Chunked Upload لتعمل مع الملفات الكبيرة عبر reverse proxies.
